## 本轮额外发现与处理

上一轮提交凭据已用于 Metadata 提交检查，但 `recoverApplying` 没有检查它。如果 closure 已提交、清理 intent 前退出，之后 QC 再次退回同一页面，进入返工页会把旧照片恢复到暂存；重新拍摄也会继承已经完成的 applying 状态。这是恢复入口的漏测，不能仅凭原来的 544 项测试宣称已覆盖。

现在恢复入口先检查精确代次的提交凭据，再读取暂存照片；已经提交的旧代次不再恢复，也不要求它的旧暂存文件仍存在。新照片不继承已完成操作的 applying 状态；真正未完成的替换、较新代次和回滚事务继续受到保护。没有改动几何/色彩算法、Python 服务或数据库 schema。

将原有用例的恢复断言改为“已提交代次不应返回待应用照片”，在修复前实际得到 File 而非 null，回归失败。另补重新暂存和旧照片文件已清理两项测试；集成宿主补模拟生产页面入口调用后按 Metadata 提交，确认不探测共享目录、不重新应用旧照片。

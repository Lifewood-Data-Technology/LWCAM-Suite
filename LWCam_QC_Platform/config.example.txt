# the LWCAM_QC_SERVER_CONFIG environment variable can point anywhere else.

# Every key is listed in backend\app\core\server_settings.py (SETTINGS_BY_KEY),

# Secrets (dbPassword, jwtSecret, openrouterApiKey) may be typed in plain text.
# On Windows the server encrypts them on its first start (they become
# `dpapi:...` values that only work on that PC).
